> **English:** Four free, step-by-step learning paths (fundamentals, blue team, application security, cloud), each step with a free official resource, a legal lab and a concrete deliverable.

# Trilhas de estudo

Uma trilha é uma sequência de etapas numeradas. Cada etapa tem quatro partes:

1. **O que aprender:** o tema da etapa.
2. **Recurso gratuito:** um material com link oficial.
3. **Laboratório:** uma prática legal, em ambiente seu ou criado para treino.
4. **Como saber que terminou:** um entregável que você consegue mostrar, como um relatório, um repositório ou um ambiente funcionando.

Só passe para a etapa seguinte quando tiver o entregável. Guarde todos eles em um repositório seu no GitHub. Ele vira seu portfólio.

## Escolha por onde começar

| Trilha | Para quem | Resultado |
|---|---|---|
| [Fundamentos](fundamentos.md) | Quem está começando do zero | Base de redes, Linux, Windows, scripts e conceitos para o primeiro emprego |
| [Blue team](blue-team.md) | Quem quer trabalhar em SOC, detecção e resposta | Laboratório de monitoramento e investigações documentadas |
| [AppSec](appsec.md) | Quem desenvolve software ou quer revisar código | Pipeline com análise de código, testes e SBOM |
| [Nuvem](nuvem.md) | Quem administra ou audita ambientes em nuvem | Ambiente de nuvem com IAM, logs e infraestrutura como código verificados |

Se você nunca configurou uma rede nem usou o terminal Linux, comece por Fundamentos. As outras três pressupõem a base dela.

## Regra de ouro: pratique só onde pode

Pratique apenas em laboratório próprio ou em ambiente que autorize o teste de forma explícita, como as plataformas de treino citadas nas trilhas. Atacar sistema de terceiros sem autorização é crime e prejudica pessoas reais. Antes de começar, leia a [legislação brasileira sobre o tema](../brasil/legislacao.md).

Cuidados práticos para qualquer trilha:

1. Rode máquinas vulneráveis e arquivos suspeitos em máquina virtual isolada, nunca no computador onde você guarda seus dados.
2. Em nuvem, use uma conta separada para estudo e configure um alerta de gasto antes de criar qualquer recurso.
3. Leia as regras de cada plataforma de treino. Elas definem o que é permitido.
