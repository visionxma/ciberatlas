# Segurança · Security

O CiberAtlas é uma lista e um conjunto de guias; não roda serviço próprio. Os riscos reais
são três: um link que passou a apontar para conteúdo malicioso, um projeto listado que foi
comprometido ou trocou de dono de forma suspeita, e uma falha no robô
(`scripts/ciberatlas.py` e `.github/workflows/`).

## Como avisar

- **Privado (preferível):** use o botão **Report a vulnerability** na aba
  [Security](https://github.com/visionxma/ciberatlas/security/advisories/new) deste repositório.
- **E-mail:** visionxma@gmail.com, assunto "CiberAtlas — segurança".

Diga qual item ou arquivo, o que você observou e, se tiver, a evidência. Um item suspeito
sai do catálogo enquanto a análise acontece.

Falha em um projeto listado deve ser reportada a quem mantém aquele projeto, pelo canal
de segurança dele.

---

**English:** report privately via **Report a vulnerability** in the
[Security tab](https://github.com/visionxma/ciberatlas/security/advisories/new) or email
visionxma@gmail.com (subject "CiberAtlas — security"). Flaws in a listed project go to that
project's maintainers.
